# 我的博客

线上：https://shenblog.vercel.app

本地写、一键发布到 GitHub、Vercel 自动上线。零依赖，只要机器上有 `node` 就能跑。

## 目录

```
blog/
├── content/posts/       文章（唯一内容源，按年份分目录）
├── content/about.md     关于页
├── public/              样式、脚本、图片（上传的图片在 uploads/）
├── scripts/build.mjs    生成静态站点到 dist/
├── scripts/serve.mjs    本地预览站点
├── scripts/shrink-image.ps1  上传图片时自动缩到 1600 宽
├── manager/             本地管理器（server.mjs + 界面 index.html/app.js）
├── site.json            站名、口号、作者、线上域名
├── 启动博客.vbs         一键打开写作窗口
└── vercel.json          Vercel 构建配置
```

## 日常写作

双击 `启动博客.vbs`：后台起服务，前台弹出一个没有地址栏、没有标签页的应用窗口（Edge/Chrome 的 `--app` 模式）。

- 左栏按「年 → 月」两级列文章，没有文章的月份不出现；补进那个月份的文章，下次保存/发布后自动冒出来。鼠标停在一行右侧出现 `×` 可直接删除。
- 标题不用写 `#`，日期和标签在标题下面一行；日期右侧还能填一个可选的时间，同一天发多篇时用它决定先后。
- 正文是 Markdown，字体 16px；图片可以直接粘贴或拖进来。
- 停止输入 4 秒自动保存到本地文件；`Ctrl+S` 立刻保存。保存不等于发布。
- 点底栏「发布到 GitHub」：本地构建校验 → `git commit` → `git push`，Vercel 约 30–60 秒上线。
- 删除文章后同样要发布一次，线上才会消失。
- 「预览」按钮可以把右侧预览面板收起；顶栏右侧的月亮/太阳图标切换深色模式。

### 改发布时间

标题下面的日期可以随便改。保存时文件会自动挪进对应年份的目录，首页、侧栏、上下篇的顺序都跟着重排。

文件名（也就是文章地址）不会跟着改——旧链接继续有效，这是故意的。

### 改站名和标语

顶栏右上角的齿轮按钮 → 站点信息，可以改站名（左上角那几个字）、标语、作者（左上角方块里的字）和简介。保存后本地立刻重建、自动提交推送，云端几十秒后同步。

### 换版式

站点一共五套版式，在「站点信息」弹窗里那一排「版式」按钮上点一下就能切：

| 按钮 | 版式 | 长相 |
| --- | --- | --- |
| 原版 | `classic` | 现在的样子：顶栏 + 可折叠年月侧栏 + 右侧目录 |
| A 廊 | `a` | 米白纸面，横向长走廊式的文章行，左侧留白极大 |
| B 水庭 | `b` | 大字标题 + 一片石灰色水庭，两栏年份，细竖线阅读进度 |
| C 红土墙 | `c` | 深色，左栏是一整面刻满文章的墙，铜色点缀 |
| D 格栅 | `d` | 12 列方格铺满屏幕，鼠标移上去其余格子退后 |

点按钮 = 只改 `site.json` 的 `theme` 字段 + 本地重建，**不提交不推送**，可以随便来回试。
旁边的「预览站点」会开一个窗口看 `http://127.0.0.1:5178/site/` 的真实效果（同一窗口复用，不用反复开新标签）。

决定好了再点「保存并同步」：这时 `theme` 跟着一起提交推送，云端几十秒后换成这套版式。

版式的样式在 `public/themes/`（`a.css b.css c.css d.css`），原版仍在 `public/style.css`。想微调颜色、字号，直接改那个 CSS 再发布就行。

### 图片

粘贴（截图直接 `Ctrl+V`）、拖入、或点工具条的图片按钮选文件，三种方式都行：

1. 图片存到 `public/uploads/年-月/<hash>.<ext>`；
2. 超过 1600 像素宽或体积偏大的，自动缩到 1600 宽再存（手机照片的 EXIF 方向也会转正）；
3. 立刻 `git commit` + `git push`，GitHub 上马上有这张图；
4. 光标处自动插入 `![说明](/uploads/...)`，同时把文章存盘。

多张一起粘贴/拖入会合成一次提交、一次推送。所以图不用等发文就在云端了，文章本身仍要点「发布」才上线。

### 快捷键

| 键 | 作用 |
| --- | --- |
| `Ctrl+S` | 立刻保存 |
| `Ctrl+K` | 打开命令面板，输入标题直接跳转文章 |
| `Ctrl+N` | 新建文章 |
| `Ctrl+B` / `Ctrl+I` | 加粗 / 斜体 |
| `Ctrl+\` | 专注模式：收起左栏和预览 |
| `Esc` | 关闭面板或弹窗 |

左栏文章标题右侧的**琥珀色小点**表示这篇有改动还没发布。

### 站点

- 手机端不占屏：左栏收成一个「目录」按钮，点开才铺出来。
- 线上文章页顶部有一条阅读进度线，右上角是自动跟随滚动的本页目录。
- 侧栏的年、月都能各自折叠，状态记在本机。
- `?theme=dark` 可以直接预览深色版。
- 版式在**构建时**决定（`site.json` 的 `theme`），不是浏览器里切；同一套站点只会有一份 HTML。

## 第一次：上传到 GitHub（只做一次）

1. 在 GitHub 新建仓库，**不要**勾 Add README。
2. 双击 `首次上传到GitHub.bat`，粘贴仓库地址（`https://github.com/你的用户名/仓库名.git`）。
3. Vercel → Add New → Project → 选中这个仓库 → Deploy。

域名已在 `site.json` 里写成 `https://shenblog.vercel.app`，用于 RSS 和 sitemap 的绝对链接。换了域名就改这里。

## 文章格式

```markdown
---
title: "标题"
date: 2026-11-15
time: 21:30      # 可选，同一天多篇时决定先后
updated: 2026-11-15
tags: [随想, 沟通]
---

正文……
```

文件名就是地址：`content/posts/2026/2026-11-15-标题.md` → `/posts/2026-11-15-标题/`。
**发布后不要手改文件名**，改了旧链接会失效。改日期只会把文件挪到对应年份的目录，文件名不动。

## 常见问题

- **点 vbs 没反应**：多半是 `node` 不在系统 PATH，重装 Node 时勾选 Add to PATH，或改用 `node manager\server.mjs` 手动起服务。
- **窗口里显示「无法连接本地服务」**：服务没起来，先手动跑一次 `node manager\server.mjs` 看报错。
- **发布提示「还不是 git 仓库」**：先跑一次 `首次上传到GitHub.bat`。
- **提交报 Author identity unknown**：`git config --global user.name "名字"`、`git config --global user.email "邮箱"`。
- **push 被拒**：GitHub 上有本地没有的提交，先 `git pull --rebase`。
- **粘贴图片没反应**：先看右下角有没有「正在上传」提示。提示「图片超过 12MB」就截小一点再贴；提示「暂不支持这种图片格式」就另存为 PNG/JPG。
- **图片传上去了但站点里是裂图**：说明文章还没发布。图片本身已经在 GitHub 上，点一次「发布」就好。
- **改了站名但线上没变**：看底栏状态，若显示「N 个改动未发布」，点「发布」补推一次。
- **想边改样式边看效果**：双击 `本地预览网站.bat`，打开 `http://127.0.0.1:4321`。
- **切了版式线上还是旧的**：切换只重建本地，点「保存并同步」才会推上去。
- **某套版式下图片显示不出来**：先 `Ctrl+S` 再点一次版式，让它重新构建一遍。
